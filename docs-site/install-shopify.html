Shopify install

Enable the Wisp chat widget in your Shopify theme.

Follow these steps after receiving your custom-distribution Shopify app install link.

1

Open the install link

Use the custom-distribution install link sent by Wisp.

2

Install the app

Review the app install screen in Shopify, then approve the install.

3

Open theme customization

Go to Online Store, then Themes, then Customize.

4

Enable the app embed

Open App embeds, turn on Chat widget, then save.

5

Check the storefront

Refresh the storefront and confirm the chat bubble appears in the lower-right corner.
